## 部署設定

### GitHub Pages 自動部署

本專案已配置 GitHub Actions 自動部署到 GitHub Pages。要啟用自動部署：

1. 前往您的 GitHub 儲存庫設定頁面
2. 點擊左側選單的 **Pages**
3. 在 **Build and deployment** 區域中：
   - **Source**: 選擇 `GitHub Actions`
4. 將此分支合併到 `main` 分支
5. GitHub Actions 將自動部署您的網站到 GitHub Pages

每次推送到 `main` 分支時，網站將自動更新。
